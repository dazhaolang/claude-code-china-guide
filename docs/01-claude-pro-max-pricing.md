## 二、五类市场方案深度对比

### 1. 原号代充 / 裸成品号（市场价：Pro ¥165~¥249/月）
- **买到的是什么**：卖家帮你完成 $20 订阅，或者发你一个刚充好 Pro 的邮箱密码。
- **最大风险**：**环境自理，封号不退**。只要你本地挂的是几十人共用的普通机场节点，或者今天连日本节点、明天切新加坡节点，极易在 1~3 天内触发 Anthropic 自动风控封禁，两百块钱直接打水漂。

### 2. 合租 / 拼车车位（市场价：¥300~¥500/人/月）
- **买到的是什么**：2~5 个人分摊一个 Max 5x 或 20x 账号。
- **最大风险**：
  1. **高峰期抢 5 小时窗口**：白天上班写代码高峰期，同车只要有一个人在跑大型仓库 Agent 循环，半小时就能把这 5 小时的公共窗口刷空，其他人全部报错限流。
  2. **平台人为二次限额**：不少拼车面板为了防止单人刷爆，会在官方窗口之外再加一道「每日美元限额」，实际可用量远低于预期。

### 3. 镜像站 / 站内积分套餐（市场价：¥259~¥1,900/月）
- **买到的是什么**：套餐名字也叫「Pro / Max」，但交付的不是 Anthropic 整号，而是站内自设的 Credits 积分池。
- **最大风险**：需要仔细核算它的 **模型倍率（如 Opus 5.5 倍率）** 与 **缓存读取倍率**；而且底层是大锅饭无状态轮询，多轮对话频繁丢失 Prompt Cache。

### 4. 纯按量 API 中转（充多少用多少）
- **适用人群**：每天只问十来个问题的轻度用户。
- **不适用人群**：Claude Code 重度开发者。因为 Claude Code 每次工具调用都会带上整棵代码树上下文，十几个回合下来就是上百万 Input Tokens，按量计费一天烧掉 ¥100~¥200 非常普遍。

### 5. 物理级「一机一线一号」独享整号月租（Claude Agent：Pro ¥205/30天）
- **买到的是什么**：**1 个官方 Pro 整号 + 1 台独立隔离容器（VM） + 1 条独享美国静态住宅 IP + 专属国内直连网关 Key（`cr_...`）**。
- **核心优势**：
  - **真独享不拼车**：账号和住宅 IP 只归你一个人用，控制台实时显示官方原生 **5h / 7d 额度百分比**。
  - **不按 Token 扣费**：¥205 全包（折合每天不到 ¥6.9），随便跑大项目重构，消耗的都是账号自带的订阅窗口额度。
  - **退订透明**：开通前可随时全额退，中途不想用了支持按天结算退剩余天数。
